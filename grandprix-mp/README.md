# 그랑프리 드라이버 — 멀티플레이

기존 오프라인 레이싱 게임에 온라인 멀티플레이를 붙인 버전이에요. Render(render.com) 무료 플랜에 올려서 친구들과 같은 방에서 달릴 수 있어요.

## 구조

```
grandprix-mp/
├─ server.js        # WebSocket 릴레이 서버 + 게임 HTML 정적 서빙 (한 주소에서 다 처리)
├─ package.json     # 의존성: ws
├─ render.yaml      # Render 배포 설정 (선택)
└─ public/
   └─ index.html    # 게임 (멀티플레이 기능 포함)
```

## 동작 방식 (왜 이렇게 했나)

- 서버는 **권위(authoritative)가 없는 릴레이**예요. 방을 관리하고, 각 플레이어가 보낸 자기 차 상태를 같은 방의 다른 사람에게 그대로 전달만 합니다.
- **각 플레이어는 자기 차만 물리로 시뮬레이션**하고, 다른 플레이어 차는 네트워크로 받은 위치를 ~110ms 지연 보간해서 부드럽게 그려요. (게임에 이미 있던 리플레이 보간 로직과 같은 원리)
- 지연에 강하고 데스싱크가 적어서, 브라우저 레이싱 게임에 흔히 쓰는 방식이에요.
- **1차 버전은 사람만** 달립니다 (AI 없음). 빈 그리드는 비워둬요. 호스트가 서킷·랩·어시스트·타이어·피트를 정하면 방 전체에 적용되고, 팀/색은 각자 고릅니다.
- 싱글플레이(레이스/퀄리파잉)는 그대로예요. 멀티플레이는 '멀티플레이' 탭에서 방에 들어갈 때만 켜집니다.

## Render에 올리기

1. 이 폴더(`grandprix-mp`)를 GitHub 저장소에 올려요.
2. [render.com](https://render.com) → **New +** → **Web Service** → 그 저장소 선택.
3. 설정:
   - **Runtime**: Node
   - **Build Command**: `npm install`
   - **Start Command**: `node server.js`
   - **Plan**: Free
   - (`render.yaml`이 있으면 Render가 자동으로 채워줘요. "Blueprint"로 만들어도 됩니다.)
4. 배포가 끝나면 `https://<이름>.onrender.com` 주소가 나와요. 그게 게임 주소이자 서버 주소예요.

> 포트는 Render가 넣어주는 `PORT` 환경변수를 자동으로 씁니다. 따로 설정할 필요 없어요.
> 무료 플랜은 15분간 접속이 없으면 잠들어요. 다시 처음 접속할 때 30초쯤 깨어나는 시간이 걸릴 수 있어요.

## 같이 플레이하는 법

1. 모두 `https://<이름>.onrender.com` 에 접속해요.
2. 메뉴의 **멀티플레이** 탭으로 가요.
   - **서버 주소**는 비워두면 돼요 (현재 접속한 주소를 자동으로 씁니다).
   - 이름을 적어요.
3. 한 명이 **방 만들기** → 화면에 4글자 **방 코드**가 떠요.
4. 나머지는 그 코드를 **방 코드**에 넣고 **방 참가**.
5. 각자 '레이스' 탭에서 **내 팀**을 고르고, 호스트가 서킷·랩 등을 정해요.
6. 호스트가 **그리드로 나가기**를 누르면 모두 함께 출발해요.

## 로컬에서 먼저 돌려보기

```bash
cd grandprix-mp
npm install
node server.js
# 브라우저에서 http://localhost:3000
```
다른 탭/다른 기기(같은 네트워크면 PC의 로컬 IP)로도 접속해 방에 참가해 보면 돼요.

## 한계 / 다음에 할 만한 것

- 사람만 달려요. AI를 넣으려면 호스트가 AI 차도 시뮬레이션해서 상태를 같이 뿌리는 "호스트 권위 AI"로 확장하면 돼요.
- 차끼리 충돌은 내 쪽에서만 밀어내는 **단방향 처리**라, 세게 부딪히면 양쪽 화면이 조금 다르게 보일 수 있어요.
- 랩/간격 계산은 각 클라이언트 기준이라 순위·갭이 몇십 ms 수준으로 다를 수 있어요.
- 출발 카운트다운은 각자 '시작' 신호를 받은 순간부터 돌아서, 네트워크 지연만큼(보통 수십 ms) 차이가 날 수 있어요.
- 더 정교하게 하려면: 서버 시간 동기화로 카운트다운 맞추기, 상태 패킷 바이너리 압축, 퀄리파잉 공동 세션 등.
